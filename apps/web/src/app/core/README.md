# core

Singleton, app-wide building blocks: typed API clients, the session and
auth interceptor, signal-based stores, and the `CalendarDate` value type
and its Material `DateAdapter`. Nothing here is a route or a feature
component — those live under `app/features/**` once later tasks add them.

This directory is empty as of task 2; it exists so later tasks (3+) have
an established home for `core/date`, `core/api`, `core/auth`, and
`core/state`.
